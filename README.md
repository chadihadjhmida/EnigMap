# 🗺️ ENIGMAP

An interactive web platform designed to help ENIG students easily navigate their campus.

---

## 🚀 Overview

**ENIGMAP** is a smart and user-friendly solution that simplifies campus navigation through an image-based interface. It allows students to visually explore the campus and receive real-time directions to classrooms and facilities.

---

## ✨ Features

- 🖼️ **Image-Based Campus Map**  
  Navigate the campus through an intuitive visual interface.

- 📍 **Interactive Navigation**  
  Click on locations directly from the map to explore routes.

- 🧭 **Step-by-Step Directions**  
  Get real-time guidance to classrooms and campus facilities.

- ⚡ **Fast & Responsive**  
  Smooth experience built for efficiency and usability.

---

## 🛠️ Tech Stack

- Node.js  
- Express.js  
- HTML / CSS / JavaScript  

---

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

```bash
# 1. Clone the repository
git clone https://github.com/chadihadjhmida/EnigMap.git

# 2. Navigate to the project folder
cd EnigMap

# 3. Install dependencies
npm install

# 4. Start the server
npm run dev
```


Then open your browser and go to:
```bash
http://localhost:3000
```
